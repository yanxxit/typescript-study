tsconfig.json 结构

flowchart TD
    A["tsconfig.json"] --> B["compilerOptions
编译选项"]
    A --> C["include
包含文件"]
    A --> D["exclude
排除文件"]

示例 
{
  "compilerOptions": {
    "target": "es2020",
    "module": "commonjs",
    "strict": true,
    "outDir": "./dist",
    "rootDir": "./src"

  "exclude": ["node_modules", "dist"],
  "extends": "./tsconfig.base.json",
  "references": [
    { "path": "./packages/core" }
  ]
}

compilerOptions 核心选项

编译器配置

target / module 核心 编译目标和模块系统
target 说明
es3 ES3（默认）
es5 ES5
es2015 ES2015（ES6）
es2017 ES2017（async/await）
es2020 ES2020（可选链、空值合并）
esnext 最新特性
module 说明
commonjs Node.js 默认
es2020/esnext ES 模块
amd AMD（RequireJS）
none 不生成模块代码

strict 严格模式选项

更严格的类型检查

strict: true 核心 严格模式 - 开启所有严格检查

strict 模式包含

flowchart TD
    A["strict: true"] --> B["strictNullChecks"]
    A --> C["strictFunctionTypes"]
    A --> D["strictBindCallApply"]
    A --> E["strictPropertyInitialization"]
    A --> F["noImplicitAny"]
    A --> G["noImplicitThis"]
    A --> H["alwaysStrict"]
选项 说明
strictNullChecks 严格空值检查
strictFunctionTypes 严格函数类型检查
noImplicitAny 禁止隐式 any
noImplicitReturns 禁止函数隐式返回 undefined
noUnusedLocals 禁止未使用的局部变量
noUnusedParameters 禁止未使用的参数

模块相关选项

模块解析和路径映射

moduleResolution / paths 核心 
{

    "types": ["node", "jest"]

}

// 使用路径映射

输出相关选项

编译输出配置

outDir / declaration / sourceMap 常用
选项 说明 推荐值
outDir 输出目录 ./dist
rootDir 源文件根目录 ./src
declaration 生成 .d.ts 声明文件 true
sourceMap 生成 source map true
noEmit 不生成输出文件 打包工具时使用

文件包含与排除

include / exclude / files

include / exclude 核心 
{
  // 指定包含的文件（支持 glob 模式）
  "include": ["src/**/*"],

  // 指定排除的文件
  "exclude": [
    "node_modules",
    "dist",
    "**/*.test.ts",
    "**/*.spec.ts"
  ]

  // 或指定具体的文件列表
  // "files": ["src/index.ts", "src/global.d.ts"]
}

// glob 模式：
// *     - 匹配任意文件
// **    - 匹配任意目录
// ?     - 匹配单个字符

extends 继承

复用配置

extends 核心 
// tsconfig.base.json（共享配置）
{
  "compilerOptions": {
    "target": "es2020",
    "module": "es2020",
    "strict": true,
    "esModuleInterop": true
  }
}

// tsconfig.json（项目配置）
{
  "extends": "./tsconfig.base.json",
  "compilerOptions": {
    "outDir": "./dist",
    "declaration": true
  }
}

// 继承规则：
// - compilerOptions 会合并（子覆盖父）
// - include/exclude/files 会被覆盖（不合并）

  "compilerOptions": {
    "composite": true,
    "declaration": true,
    "outDir": "./dist"
  }
}

最佳实践

配置建议

推荐配置 核心 
// 1. 始终开启 strict: true
{
  "compilerOptions": {
    "strict": true
  }
}

// 2. 使用 extends 复用配置
{
  "extends": "./tsconfig.base.json"
}

// 3. 使用 paths 简化导入
{
  "compilerOptions": {
    "paths": {
      "@/*": ["src/*"]
    }
  }
}

// 4. 排除不需要的文件
{
  "exclude": ["node_modules", "dist", "**/*.test.ts"]
}

// 5. 使用 skipLibCheck 加速编译
{
  "compilerOptions": {
    "skipLibCheck": true
  }
}
速查表
选项 推荐值 说明
target es2020 编译目标
module es2020 或 commonjs 模块系统
strict true 严格模式
esModuleInterop true ES/CJS 互操作
skipLibCheck true 跳过库检查
declaration true 生成声明文件
