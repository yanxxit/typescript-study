this-less 函数推断改进

无 this 函数的类型推断

改进方法语法的推断 新特性
TS 5.x - 报错 
// ❌ TypeScript 5.x：方法语法报错
callIt({
  consume(y) { return y.toFixed() },  // y 是 unknown
  produce(x: number) { return x * 2 }
})
TS 6.0 - 正常工作 
// ✅ TypeScript 6.0：方法语法也能正常工作
callIt({
  consume(y) { return y.toFixed() },  // y 正确推断为 number
  produce(x: number) { return x * 2 }
})

原理：TypeScript 6.0 检查函数是否实际使用了 this。如果函数没有使用 this，则不将其视为上下文敏感函数，从而优先参与类型推断。

Subpath Imports 以 #/ 开头

更简洁的导入路径

#/ 前缀 新特性
package.json 
{
  "imports": {
    // 之前：需要额外的段名
    "#root/*": "./dist/*"

    // 现在：直接使用 #/
    "#/*": "./dist/*"
  }
}
导入 
// 使用 #/ 前缀导入
import * as utils from '#/utils.js'

// 要求 moduleResolution 为 nodenext 或 bundler

Map 的 getOrInsert 方法

Upsert 操作

getOrInsert / getOrInsertComputed 新特性
之前 - 冗长 
function processOptions(options: Map<string, unknown>) {
  let value: unknown
  if (options.has('strict')) {
    value = options.get('strict')
  } else {
    value = true
    options.set('strict', value)
  }
}
现在 - 简洁 
function processOptions(options: Map<string, unknown>) {
  const value = options.getOrInsert('strict', true)
}

// 使用计算函数
const value = someMap.getOrInsertComputed('key', () => {
  return computeExpensiveValue()
})

RegExp.escape

正则表达式转义

RegExp.escape 新特性
新 API 
function matchWholeWord(word: string, text: string) {
  const escapedWord = RegExp.escape(word)
  const regex = new RegExp(`\\b${escapedWord}\\b`, 'g')
  return text.match(regex)
}

// 自动转义特殊字符：* + ? ( ) 等

迁移到 TypeScript 6.0

升级指南

迁移步骤 指南
推荐配置 
{
  "compilerOptions": {
    // 1. 设置 types
    "types": ["node", "jest"],

    // 2. 设置 rootDir
    "rootDir": "./src",

    // 3. 设置 module 和 moduleResolution
    "module": "esnext",
    "moduleResolution": "bundler",

    // 4. 设置 target
    "target": "es2020",

    // 5. 如果需要旧行为
    "strict": false,
    "ignoreDeprecations": "6.0"
  }
}
常见错误修复 
// 错误：Cannot find module '...'
// 修复：添加 types
{

    "types": ["node"]
  }
}

// 错误：文件输出到错误目录

{
  "compilerOptions": {
    "rootDir": "./src"
  }
}

// 错误：Import assertions have been replaced
// 修复：使用 with 代替 asserts
import blob from './data.json' with { type: 'json' }
