什么是类型守卫

在运行时检查类型

Type Guard 核心 类型守卫 - 运行时类型缩窄

类型守卫是在运行时检查类型的技术，让 TypeScript 能够在特定代码块中推断出更精确的类型。

类型守卫工作流程

flowchart LR
    A["string | number"] --> B["typeof 检查"]
            B --> C["string"]
            B --> D["number"]
示例代码 
function processValue(value: string | number) {
  // 此时 value 是 string | number
  if (typeof value === 'string') {
    // 此时 value 是 string
    return value.toUpperCase()
  } else {
    // 此时 value 是 number
    return value.toFixed(2)
  }
}

function format(value: string | number | boolean): string {
  if (typeof value === 'string') {
    return value.toUpperCase()  // string
  } else if (typeof value === 'number') {
    return value.toFixed(2)     // number
  } else {
    return value ? '是' : '否'  // boolean
  }
}

检查类实例

x instanceof Class 核心 instanceof 守卫 - 类实例检查

instanceof 类型缩窄

flowchart LR
    A["Bird | Fish"] --> B["instanceof Bird"]
            B --> C["Bird"]
            B --> D["Fish"]
示例代码 
class Bird {
  fly() { console.log('飞翔') }
  layEggs() { console.log('下蛋') }
}

class Fish {
  swim() { console.log('游泳') }
  layEggs() { console.log('下蛋') }
}

function move(animal: Bird | Fish) {
  if (animal instanceof Bird) {
    animal.fly()    // Bird
  } else {
    animal.swim()   // Fish
  }
}

自定义类型守卫

类型谓词（Type Predicate）

value is Type 进阶 自定义守卫 - 复杂类型判断

类型谓词工作流程

flowchart LR
    A["isFish(pet)"] --> B{"返回 true?"}
            B -->|Yes| C["pet: Fish"]
            B -->|No| D["pet: Bird"]
示例代码 
interface Fish {
  name: string
  swim(): void
}

interface Bird {
  name: string
  fly(): void
}

// 类型谓词：pet is Fish
function isFish(pet: Fish | Bird): pet is Fish {
  return (pet as Fish).swim !== undefined
}

function move(pet: Fish | Bird) {
  if (isFish(pet)) {
    pet.swim()  // Fish
  } else {
    pet.fly()   // Bird
  }
}

断言函数

前置条件验证

asserts value is Type 进阶 断言函数 - 失败时抛出错误
示例代码 
// 断言函数：失败时抛出错误
function assertIsString(
  value: unknown
): asserts value is string {
  if (typeof value !== 'string') {
    throw new Error('期望字符串类型')
  }
}

function process(value: unknown) {
  assertIsString(value)
  // value 在这里是 string
  console.log(value.toUpperCase())
}

// 实际应用：非空断言
function assertDefined<T>(
  value: T | null | undefined,
  name: string
): asserts value is T {
  if (value === null || value === undefined) {
    throw new Error(`${name} 不能为空`)
  }
}

function processUser(user: { name?: string | null }) {
  assertDefined(user.name, 'name')
  // user.name 在这里是 string
  console.log(user.name.toUpperCase())
}

可辨识联合

使用判别字段区分类型

switch (shape.kind) 核心 可辨识联合 - 最常用的类型守卫模式

可辨识联合结构

flowchart TD
    A["Shape 联合类型"] --> B["Circle
kind: 'circle'"]
    A --> C["Rectangle
kind: 'rectangle'"]
    A --> D["Triangle
kind: 'triangle'"]
    B --> E["switch(kind)"]
    C --> E
    D --> E
示例代码 
interface Circle {
  kind: 'circle'    // 判别字段
  radius: number
}

interface Rectangle {
  kind: 'rectangle' // 判别字段
  width: number
  height: number
}

interface Triangle {
  kind: 'triangle'  // 判别字段
  base: number
  height: number
}

type Shape = Circle | Rectangle | Triangle

function area(shape: Shape): number {
  switch (shape.kind) {
    case 'circle':
      return Math.PI * shape.radius ** 2
    case 'rectangle':
      return shape.width * shape.height
    case 'triangle':
      return (shape.base * shape.height) / 2
  }
}

穷尽检查

确保所有情况都被处理

never 穷尽检查 进阶 编译时确保完整覆盖
示例代码 
type Shape =
  | { kind: 'circle'; radius: number }
  | { kind: 'rectangle'; width: number; height: number }

function area(shape: Shape): number {
  switch (shape.kind) {
    case 'circle':
      return Math.PI * shape.radius ** 2
    case 'rectangle':
      return shape.width * shape.height
    default:
      // 如果漏掉了某个 case，这里会报错
      const _exhaustive: never = shape
      return _exhaustive
  }
}

// 如果添加新的 Shape 类型但没有处理：
// Type '{ kind: "triangle"; ... }' is not assignable to type 'never'

    console.error(`错误 ${response.code}: ${response.message}`)  // ErrorResponse
  }

案例 2：JSON 解析验证 常用 
interface User {
  id: number
  name: string
  email: string
}

function isUser(value: unknown): value is User {
  return (
    typeof value === 'object' &&
    value !== null &&
    'id' in value &&
    'name' in value &&
    'email' in value
  )
}

function parseUser(json: string): User | null {
  try {
    const data = JSON.parse(json)
    if (isUser(data)) {
      return data  // User
    }
    return null
  } catch {
    return null
  }
}

  }

案例 4：表单验证 常用 
interface FieldError {
  type: 'error'
  field: string
  message: string
}

interface FieldSuccess {
  type: 'success'
  field: string
  value: any
}

type FieldResult = FieldError | FieldSuccess

function processField(result: FieldResult) {
  if (result.type === 'error') {
    console.error(`${result.field}: ${result.message}`)
    return null
  }
  return result.value
}

function validateEmail(email: string): FieldResult {
  if (!email.includes('@')) {
    return { type: 'error', field: 'email', message: '邮箱格式不正确' }
  }
  return { type: 'success', field: 'email', value: email }
}
