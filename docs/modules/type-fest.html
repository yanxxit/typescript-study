基础类型

匹配原始值、类和 TypedArray 的基础工具

Primitive 核心 原始类型

匹配任何原始类型：string、number、bigint、boolean、symbol、null、undefined。

匹配的类型
string | number | boolean
bigint | symbol | null | undefined
Primitive
排除的类型
object, array, function, class...
示例代码 
import type { Primitive } from 'type-fest'

function printValue(value: Primitive) {
  console.log(value)
}

printValue('hello')  // ✅ string
printValue(42)       // ✅ number
printValue(true)     // ✅ boolean
printValue({})    // ❌ 对象不是原始类型
Class / Constructor 常用 类 / 构造函数

Class 匹配 class 本身，Constructor 匹配 class 的构造函数签名。

Class vs Constructor 匹配关系

flowchart LR
    A["class Animal"] --> B["Class 类型"]
    A --> C["Constructor 类型"]
    B --> D["new Animal()"]
    C --> E["constructor(name)"]
示例代码 
import type { Class, Constructor } from 'type-fest'

class Animal {
  name: string
  constructor(name: string) { this.name = name }
}

// Class 匹配类本身
function createInstance<T extends Class>(cls: T): InstanceType<T> {
  return new (cls as any)()
}

// Constructor 匹配构造函数签名
function getClassConstructor<T extends Constructor>(ctr: T): T {
  return ctr
}
TypedArray 常用 类型化数组

匹配任何 TypedArray（如 Uint8Array、Float64Array 等），用于处理二进制数据。

示例代码 
import type { TypedArray } from 'type-fest'

function sum(arr: TypedArray): number {
  let total = 0
  for (const num of arr) total += num
  return total
}

sum(new Uint8Array([1, 2, 3]))    // 6
sum(new Float64Array([1.5, 2.5])) // 4

对象工具类型

转换和操作对象类型的工具集合

Except<Type, Keys> 核心 排除类型 - 从对象中排除指定键

类似 TypeScript 内置的 Omit，但更灵活——可以排除不在类型定义中的键。

示例代码 
import type { Except } from 'type-fest'

interface User {
  id: number
  name: string
  password: string
  email: string
}

// 只暴露给前端的安全字段
type SafeUser = Except<User, 'password'>
// { id: number; name: string; email: string }
Writable / WritableDeep 核心 可写类型 - 移除 readonly 修饰符

Writable 移除顶层 readonly，WritableDeep 深层移除所有 readonly。

readonly Config
readonly host: string
readonly db: { readonly name: string }
→ WritableDeep →
可变 Config
host: string
db: { name: string }
示例代码 
import type { Writable, WritableDeep } from 'type-fest'

interface Config {
  readonly host: string
  readonly port: number
  readonly db: {
    readonly name: string
  }
}

// Writable: 只移除顶层 readonly
type MutableConfig = Writable<Config>
// { host: string; port: number; readonly db: { readonly name: string } }

// WritableDeep: 深层移除所有 readonly
type DeepMutableConfig = WritableDeep<Config>
// { host: string; port: number; db: { name: string } }
ReadonlyDeep<Type> 核心 深层只读类型 - 递归应用 readonly

WritableDeep 的反操作。深层将所有属性变为只读，非常适合 React 组件的 props。

示例代码 
import type { ReadonlyDeep } from 'type-fest'

interface Config {
  db: {
    host: string
    port: number
  }
  cache: string[]
}

type ImmutableConfig = ReadonlyDeep<Config>
// {
//   readonly db: { readonly host: string; readonly port: number }
//   readonly cache: readonly string[]
// }

// React 组件 props 应该是不可变的
type Props = ReadonlyDeep<{
  user: { name: string; age: number }
  onUpdate: () => void
}>
Merge / MergeDeep 核心 合并类型 - 合并两个对象类型

合并两个类型，第二个类型的键覆盖第一个。与交叉类型 A & B 不同，Merge 是后者覆盖前者。

Merge vs 交叉类型

flowchart LR
    A["类型 A
{x: number}"] --> B["Merge"]
    C["类型 B
{y: string}"] --> B
    B --> D["{x: number;
y: string}"]
    
    A --> E["交叉 &"]
    C --> E
    E --> F["{x: number;
y: string}"]
示例代码 
import type { Merge, MergeDeep } from 'type-fest'

interface A { x: number; y: string }
interface B { y: number; z: boolean }

type Result = Merge<A, B>
// { x: number; y: number; z: boolean }  ← y 被覆盖

// MergeDeep 支持嵌套对象合并
interface DeepA { user: { name: string; age: number } }
interface DeepB { user: { email: string } }

type DeepResult = MergeDeep<DeepA, DeepB>
// { user: { name: string; age: number; email: string } }

SetOptional<Type, Keys>

将指定键设为可选

import type { SetOptional } from 'type-fest'

interface User {
  id: number
  name: string
  email?: string
}

// id 变为可选
type Create = SetOptional<
  User, 'id'
>

SetRequired<Type, Keys>

将指定键设为必选

import type { SetRequired } from 'type-fest'

interface User {
  id: number
  name: string
  email?: string
}

// name 和 email 变为必选
type Update = SetRequired<
  User, 'name' | 'email'
>

RequiredDeep<Type>

深层将所有属性设为必选

import type { RequiredDeep } from 'type-fest'

interface Config {
  db?: {
    host?: string
    port?: number
  }
}

type Strict = RequiredDeep<
  Config
>
// { db: { host: string; port: number } }

PartialDeep<Type>

深层将所有属性设为可选

import type { PartialDeep } from 'type-fest'

interface Todo {
  title: string
  meta: {
    createdAt: Date
  }
}

type Partial = PartialDeep<
  Todo
>
// { title?: string; meta?: { createdAt?: Date } }
PickDeep / OmitDeep 进阶 深层选取/排除 - 使用点号路径语法

使用点号路径语法（如 'user.name'）从深层嵌套对象中选取或排除属性。

示例代码 
import type { PickDeep, OmitDeep } from 'type-fest'

interface AppState {
  user: {
    name: string
    email: string
    settings: {
      theme: string
      lang: string
    }
  }
  posts: { id: number; title: string }[]
}

// PickDeep: 使用点号路径选择深层属性
type UserBasic = PickDeep<AppState, 'user.name' | 'user.email'>
// { user: { name: string; email: string } }

// OmitDeep: 排除指定路径
type WithoutPosts = OmitDeep<AppState, 'posts'>
// { user: { name: string; email: string; settings: { theme: string; lang: string } } }
LiteralUnion<Literal, Primitive> 进阶 字面量联合 - 兼顾自动补全和灵活性

让 IDE 在联合类型中提供自动补全，同时允许自定义值。完美解决"预设值 + 自定义值"的需求。

普通联合类型
'primary' | 'secondary' | 'danger'
LiteralUnion
自动补全 + 自定义
预设值 + string
示例代码 
import type { LiteralUnion } from 'type-fest'

// 普通联合：只能用预设值
type Variant1 = 'primary' | 'secondary' | 'danger'

// LiteralUnion：自动补全 + 允许自定义
type Variant2 = LiteralUnion<
  'primary' | 'secondary' | 'danger',
  string
>

const v1: Variant2 = 'primary'    // ✅ IDE 自动补全
const v2: Variant2 = 'danger'     // ✅ IDE 自动补全
const v3: Variant2 = 'my-custom'  // ✅ 也允许自定义值
Tagged<Type, Tag> 进阶 品牌类型 - 防止类型混淆

创建标签类型（品牌类型），防止不同类型之间的意外混淆。虽然底层类型相同，但编译器会阻止混用。

Tagged 类型安全机制

flowchart LR
    A["UserId
Tagged<number, 'UserId'>"] --> B["getUser(id)"]
    C["OrderId
Tagged<number, 'OrderId'>"] --> D["getOrder(id)"]
    
    E["userId: UserId"] --> B
    F["orderId: OrderId"] --> B
    F --> D
    
    style F fill:#f85149,stroke:#f85149,color:#fff
示例代码 
import type { Tagged, UnwrapTagged } from 'type-fest'

// 定义不同类型的 ID
type UserId = Tagged<number, 'UserId'>
type OrderId = Tagged<number, 'OrderId'>

function getUser(id: UserId) { /* ... */ }
function getOrder(id: OrderId) { /* ... */ }

const userId = 1 as UserId
const orderId = 2 as OrderId

getUser(userId)    // ✅ 类型匹配
getUser(orderId)   // ❌ 类型不匹配，防止传错 ID！

// UnwrapTagged: 提取原始类型
type RawUserId = UnwrapTagged<UserId>  // number
Exact<Type> 进阶 精确类型 - 禁止额外属性

严格检查类型，不允许传入未声明的额外属性。解决 TypeScript 结构化类型系统的弱点。

示例代码 
import type { Exact } from 'type-fest'

interface ButtonProps {
  color: string
  size: number
  onClick: () => void
}

// 普通类型：允许额外属性
function createButton1(props: ButtonProps) {}
createButton1({ color: 'red', size: 10, onClick: () => {}, extra: true })  // ✅ 没报错

// Exact：严格检查
function createButton2(props: Exact<ButtonProps, ButtonProps>) {}
createButton2({ color: 'red', size: 10, onClick: () => {} })  // ✅
// createButton2({ ..., extra: true })  // ❌ 不允许额外属性
ValueOf<Type> 常用 值类型 - 获取对象所有值的联合类型
示例代码 
import type { ValueOf } from 'type-fest'

const STATUS = {
  PENDING: 'pending',
  ACTIVE: 'active',
  DELETED: 'deleted',
} as const

type Status = ValueOf<typeof STATUS>
// 'pending' | 'active' | 'deleted'
ConditionalPick<Type, Condition> 进阶 条件选取 - 按条件筛选键
示例代码 
import type { ConditionalPick } from 'type-fest'

interface Mixed {
  name: string
  age: number
  greet: () => void
  count: number
  action: (x: number) => void
}

// 只保留函数类型的键
type OnlyFunctions = ConditionalPick<Mixed, Function>
// { greet: () => void; action: (x: number) => void }

// 只保留 number 类型的键
type OnlyNumbers = ConditionalPick<Mixed, number>
// { age: number; count: number }

字符串操作类型

编译时字符串转换工具

CamelCase / KebabCase / PascalCase / SnakeCase 核心 命名风格转换
输入
'foo_bar'
→ CamelCase → 'fooBar'
→ PascalCase → 'FooBar'
→ KebabCase → 'foo-bar'
→ SnakeCase → 'foo_bar'
示例代码 
import type {
  CamelCase, KebabCase,
  PascalCase, SnakeCase
} from 'type-fest'

type A = CamelCase<'foo_bar'>     // 'fooBar'
type B = KebabCase<'fooBar'>     // 'foo-bar'
type C = PascalCase<'foo_bar'>   // 'FooBar'
type D = SnakeCase<'fooBar'>     // 'foo_bar'

实际应用：API 字段名转换 

// Python/Ruby 后端返回 snake_case，前端需要 camelCase
interface RawUser {
  first_name: string
  last_name: string
  created_at: string
}

type User = CamelCasedProperties<RawUser>
// { firstName: string; lastName: string; createdAt: string }
Trim / Split / Replace 常用 字符串裁剪、分割、替换
示例代码 
import type { Trim, Split, Replace } from 'type-fest'

// Trim: 裁剪首尾空格
type A = Trim<'  hello  '>      // 'hello'

// Split: 按分隔符分割字符串
type B = Split<'a.b.c', '.'>    // ['a', 'b', 'c']

// Replace: 替换字符串
type C = Replace<'foo_bar', '_', '-'>  // 'foo-bar'

数组/元组类型

操作数组和元组的工具集合

Arrayable<Type> 常用 可数组类型 - 值可以是单个或数组
Arrayable<number>
number | number[]
→ ensureArray →
输出
number[]
示例代码 
import type { Arrayable } from 'type-fest'

function ensureArray(value: Arrayable<number>): number[] {
  return Array.isArray(value) ? value : [value]
}

ensureArray(1)       // [1]
ensureArray([1, 2])  // [1, 2]
TupleToUnion<Tuple> 常用 元组转联合 - 将元组转换为联合类型

import type { TupleToUnion } from 'type-fest'

type Colors = TupleToUnion<['red', 'green', 'blue']>
// 'red' | 'green' | 'blue'

import type { FixedLengthArray } from 'type-fest'

函数类型

操作函数签名的工具集合

SetReturnType<Type, ReturnType> 常用 设置返回类型 - 更改函数返回类型
示例代码 
import type { SetReturnType } from 'type-fest'

function add(a: number, b: number): number {
  return a + b
}

// 将返回类型改为字符串
type StringAdd = SetReturnType<typeof add, string>
// (a: number, b: number) => string
SetParameterType<Type, Index, ParameterType> 常用 设置参数类型 - 替换函数参数类型
示例代码 
import type { SetParameterType } from 'type-fest'

function greet(name: string, age: number): string {
  return `Hello ${name}, ${age}`
}

// 将第 0 个参数从 string 改为 number
type NumericGreet = SetParameterType<typeof greet, 0, number>
// (name: number, age: number) => string

异步类型

处理 Promise 和异步操作的工具

Promisable<Type> 核心 可 Promise 类型 - 同步或异步返回
示例代码 
import type { Promisable } from 'type-fest'

// 返回值可以是同步或异步
function getData(): Promisable<string> {
  if (Math.random() > 0.5) {
    return 'sync data'  // 同步返回
  }
  return Promise.resolve('async data')  // 异步返回
}
AsyncReturnType<Type> 常用 异步返回类型 - 解包 Promise 返回值
示例代码 
import type { AsyncReturnType } from 'type-fest'

  return { id: 1, name: 'Alice' }
}

type UserType = AsyncReturnType<typeof fetchUser>
// { id: number; name: string }  // 自动解包 Promise

类型守卫

类型层面的条件判断工具

If / IsAny / IsNever / IsUnknown 核心 条件判断类型

类型守卫工作流程

flowchart TD
    A["输入类型 T"] --> B{"IsAny?"}
    B -->|true| C["返回 true"]
    B -->|false| D{"IsNever?"}
    D -->|true| E["返回 true"]
    D -->|false| F["返回 false"]
    
    G["If<条件, A, B>"] --> H{"条件?"}
    H -->|true| I["返回 A"]
    H -->|false| J["返回 B"]
示例代码 
import type { If, IsAny, IsNever, IsUnknown } from 'type-fest'

// IsAny: 判断是否为 any
type A = IsAny<any>     // true
type B = IsAny<string>  // false

// IsNever: 判断是否为 never
type C = IsNever<never>   // true
type D = IsNever<string>  // false

// IsUnknown: 判断是否为 unknown
type E = IsUnknown<unknown>  // true
type F = IsUnknown<any>      // false

// If: 条件执行
type Result = If<IsAny<string>, 'yes', 'no'>  // 'no'
IsLiteral / IsStringLiteral / IsNumericLiteral 常用 字面量类型判断
示例代码 
import type { IsLiteral, IsStringLiteral, IsNumericLiteral } from 'type-fest'

type A = IsLiteral<'hello'>      // true（字符串字面量）
type B = IsLiteral<string>       // false（宽泛类型）
type C = IsStringLiteral<'foo'>  // true
type D = IsNumericLiteral<42>    // true
type E = IsNumericLiteral<number> // false

条件逻辑类型

类型层面的布尔运算

And / Or / Xor / AndAll / OrAll 进阶 布尔逻辑运算

布尔逻辑真值表

flowchart LR
    A["And"] --> B["true AND true = true"]
    A --> C["true AND false = false"]
    
    D["Or"] --> E["false OR true = true"]
    D --> F["false OR false = false"]
    
    G["Xor"] --> H["true XOR false = true"]
    G --> I["true XOR true = false"]
示例代码 
import type { And, Or, Xor, AndAll, OrAll } from 'type-fest'

// 基本运算
type A = And<true, true>     // true
type B = And<true, false>    // false
type C = Or<false, true>     // true
type D = Xor<true, false>    // true
type E = Xor<true, true>     // false

// 批量运算
type F = AndAll<[true, true, true]>     // true
type G = AndAll<[true, false, true]>  // false
type H = OrAll<[false, false, true]>  // true
type I = OrAll<[false, false, false]> // false

对比：type-fest vs TypeScript 内置

何时需要引入 type-fest

场景 TypeScript 内置 type-fest
排除键 Omit<T, K> Except<T, K>
深层可选 — PartialDeep<T>
深层必选 — RequiredDeep<T>
深层只读 Readonly<T>（浅） ReadonlyDeep<T>（深）
深层可写 — WritableDeep<T>
合并类型 A & B（交叉） Merge<A, B>（后者覆盖）
命名风格转换 — CamelCase<T> 等
JSON 类型 — JsonValue 等
品牌类型 — Tagged<T, N>
字面量联合 — LiteralUnion<T>
类型守卫 — IsAny<T> 等

小结

  • 对象操作：Except、Merge、PartialDeep、RequiredDeep、WritableDeep/ReadonlyDeep 是最常用的
  • 字符串操作：命名风格转换（CamelCase 等）在对接 API 时非常实用
  • 类型守卫：If、IsAny、IsNever 可以在类型层面做条件判断
  • JSON/异步：JsonValue、Promisable 解决了序列化和异步场景的类型表达
  • 高级场景：Tagged 防止类型混淆，LiteralUnion 兼顾自动补全和灵活性，Simplify 改善 IDE 体验

type-fest 不是"全都要用"，而是按需引入——当你发现 TypeScript 内置类型搞不定时，先来这里找找。
