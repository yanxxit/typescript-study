什么是枚举

一组命名常量的集合

enum 核心 枚举 - 用有意义的名字表示常量

枚举是一组命名常量的集合，让代码更有意义，提高可读性和可维护性。

❌ 没有枚举
if (status === 0) ...
→ 枚举 →
✅ 有枚举
if (status === Status.Pending) ...
示例代码 
// 没有枚举：使用数字，含义不明确
function setStatus(status: number) {
  if (status === 0) { /* ... */ }
  if (status === 1) { /* ... */ }
}

// 有枚举：使用有意义的名字
enum Status {
  Pending,    // 0
  Active,     // 1
  Deleted     // 2
}

function setStatus(status: Status) {
  if (status === Status.Pending) { /* ... */ }
  if (status === Status.Active) { /* ... */ }
}

数字枚举

默认从 0 开始递增

enum Direction { Up, Down, Left, Right } 核心 数字枚举 - 成员是数字

数字枚举值递增

flowchart LR
    A["Up"] --> B["0"]
    C["Down"] --> D["1"]
    E["Left"] --> F["2"]
    G["Right"] --> H["3"]
示例代码 
// 基本数字枚举（从 0 开始）
enum Direction {
  Up,      // 0
  Down,    // 1
  Left,    // 2
  Right    // 3
}

console.log(Direction.Up)     // 0
console.log(Direction.Down)   // 1

// 指定初始值
enum Color {
  Red = 1,
  Green = 2,
  Blue = 4
}

// 部分指定初始值（自动递增）
enum Status {
  Pending = 0,
  Active,      // 1
  Deleted      // 2
}

字符串枚举

每个成员都是字符串值

enum Direction { Up = 'UP', Down = 'DOWN' } 核心 字符串枚举 - 调试更友好
数字枚举
console.log(Status.Pending) // 0
vs
字符串枚举
console.log(Status.Pending) // 'PENDING'
示例代码 
enum Direction {
  Up = 'UP',
  Down = 'DOWN',
  Left = 'LEFT',
  Right = 'RIGHT'
}

console.log(Direction.Up)  // 'UP'

// 字符串枚举在调试时更友好
enum HttpStatus {
  OK = 'OK',
  NotFound = 'Not Found',
  Error = 'Internal Server Error'
}

console.log(HttpStatus.NotFound)  // 'Not Found'

枚举的使用

函数参数、对象属性、Map 键

枚举使用场景 常用
示例代码 
// 作为函数参数
enum Season {
  Spring,
  Summer,
  Autumn,
  Winter
}

function getSeasonName(season: Season): string {
  switch (season) {
    case Season.Spring: return '春天'
    case Season.Summer: return '夏天'
    case Season.Autumn: return '秋天'
    case Season.Winter: return '冬天'
  }
}

// 作为对象属性
enum Role {
  Admin = 'ADMIN',
  User = 'USER',
  Guest = 'GUEST'
}

interface User {
  name: string
  role: Role
}

// 作为 Map 的键
enum Color {
  Red,
  Green,
  Blue
}

const colorNames = new Map<Color, string>()
colorNames.set(Color.Red, '红色')
colorNames.set(Color.Green, '绿色')
colorNames.set(Color.Blue, '蓝色')

console.log(colorNames.get(Color.Red))  // '红色'

反向映射

从值获取成员名

Color[0] → 'Red' 常用 反向映射 - 仅数字枚举支持
正向映射
Color.Red → 0
↔
反向映射
Color[0] → 'Red'
示例代码 
enum Color {
  Red,    // 0
  Green,  // 1
  Blue    // 2
}

// 正向映射：成员名 → 值
console.log(Color.Red)   // 0

// 反向映射：值 → 成员名
console.log(Color[0])    // 'Red'
console.log(Color[1])    // 'Green'

注意

字符串枚举和 const 枚举没有反向映射！

const 枚举

编译时内联，更小的包体积

const enum 进阶 常量枚举 - 编译后完全移除

const 编译流程

flowchart LR
    A["const enum Color
{ Red, Green, Blue }"] --> B["编译器"]
            B --> C["const color = 0
（直接替换为值）"]
示例代码 
// const 枚举
const enum Direction {
  Up,
  Down,
  Left,
  Right
}

// 使用
const dir = Direction.Up

// 编译后变成：
// const dir = 0
特性 普通枚举 const 枚举
编译结果 生成运行时对象 完全内联，无对象
包体积 较大 更小
反向映射 ✅ 支持 ❌ 不支持
动态访问 ✅ 支持 ❌ 不支持

枚举 vs 联合类型

如何选择

选择建议
枚举
enum Direction { Up, Down }
vs
联合类型
type Dir = 'up' | 'down'
场景 推荐
简单字符串常量 联合类型（轻量）
需要数字映射 枚举
需要反向映射 枚举
需要运行时值 枚举
极致包体积 const 枚举 或 联合类型
对比示例 
// 使用枚举
enum Direction {
  Up,
  Down,
  Left,
  Right
}

// 使用联合类型（更轻量）
type Direction2 = 'up' | 'down' | 'left' | 'right'

// 两者都可以
function move(dir: Direction) { /* ... */ }
function move2(dir: Direction2) { /* ... */ }

编译结果

枚举编译后的 JavaScript 代码

编译对比
普通枚举编译结果 
// TypeScript
enum Color {
  Red,
  Green,
  Blue
}

// 编译后 JavaScript
var Color;
(function (Color) {
  Color[Color["Red"] = 0] = "Red";
  Color[Color["Green"] = 1] = "Green";
  Color[Color["Blue"] = 2] = "Blue";
})(Color || (Color = {}));
const 枚举编译结果 
// TypeScript
const enum Color {
  Red,
  Green,
  Blue
}

// 编译后 JavaScript（内联）
const color = 0;  // Color.Red 被替换为 0

实战案例

真实场景中的应用

案例 1：订单状态机 常用 
enum OrderStatus {
  Pending = 'PENDING',
  Processing = 'PROCESSING',
  Shipped = 'SHIPPED',
  Delivered = 'DELIVERED',
  Cancelled = 'CANCELLED'
}

function getNextStatus(current: OrderStatus): OrderStatus | null {
  const transitions: Record<OrderStatus, OrderStatus | null> = {
    [OrderStatus.Pending]: OrderStatus.Processing,
    [OrderStatus.Processing]: OrderStatus.Shipped,
    [OrderStatus.Shipped]: OrderStatus.Delivered,
    [OrderStatus.Delivered]: null,
    [OrderStatus.Cancelled]: null
  }
  return transitions[current]
}
案例 2：位运算权限 进阶 
enum Permission {
  Read = 1 << 0,    // 1
  Write = 1 << 1,   // 2
  Execute = 1 << 2, // 4
  Admin = 1 << 3    // 8
}

// 组合权限
function combinePermissions(...perms: Permission[]): number {
  return perms.reduce((acc, p) => acc | p, 0)
}

// 检查权限
function hasPermission(userPerm: number, required: Permission): boolean {
  return (userPerm & required) === required
}

// 使用
const userPerms = combinePermissions(Permission.Read, Permission.Write)
hasPermission(userPerms, Permission.Read)     // true
hasPermission(userPerms, Permission.Execute)  // false
案例 3：API 错误码 常用 
enum ErrorCode {
  BadRequest = 400,
  Unauthorized = 401,
  Forbidden = 403,
  NotFound = 404,
  Validation = 422,
  Internal = 500,
  ServiceUnavailable = 503
}

interface ApiError {
  code: ErrorCode
  message: string
  details?: any
}

function createError(
  code: ErrorCode,
  message: string,
  details?: any
): ApiError {
  return { code, message, details }
}

const notFoundError = createError(ErrorCode.NotFound, '用户不存在')
案例 4：日志级别 常用 
enum LogLevel {
  Debug = 'DEBUG',
  Info = 'INFO',
  Warn = 'WARN',
  Error = 'ERROR'
}

function createLogger(level: LogLevel) {
  return {
    debug: (msg: string) => {
      if (level === LogLevel.Debug) console.log(`[DEBUG] ${msg}`)
    },
    info: (msg: string) => {
      if (level === LogLevel.Info || level === LogLevel.Debug)
        console.log(`[INFO] ${msg}`)
    },
    warn: (msg: string) => console.warn(`[WARN] ${msg}`),
    error: (msg: string) => console.error(`[ERROR] ${msg}`)
  }
}

const logger = createLogger(LogLevel.Info)
logger.info('服务器启动')    // [INFO] 服务器启动
logger.debug('调试信息')     // 不会输出
