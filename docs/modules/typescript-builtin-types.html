对象操作

转换和操作对象类型的工具集合

Partial<Type> 核心 部分类型 - 将所有属性变为可选

将类型 T 的所有属性变为可选。这在更新操作中特别有用——你只需要传递要修改的字段。

原始类型
{
  title: string
  desc: string
  done: boolean
}
→ Partial →
结果类型
{
  title?: string
  desc?: string
  done?: boolean
}
示例代码 
interface Todo {
  title: string
  description: string
  completed: boolean
}

// 更新时只需传部分字段
function updateTodo(
  todo: Todo,
  fields: Partial<Todo>
): Todo {
  return { ...todo, ...fields }
}

const todo: Todo = {
  title: '学习 TypeScript',
  description: '掌握工具类型',
  completed: false
}

// 只更新 completed，其他字段保持不变
updateTodo(todo, { completed: true })

实现原理

Partial<T> 通过映射类型实现，遍历 T 的所有键，添加 ? 修饰符：

type Partial<T> = { [P in keyof T]?: T[P] }

实际应用场景

  • REST API 的 PATCH 请求体
  • React 组件的 Props 更新
  • 表单的可选字段验证
Required<Type> 核心 必选类型 - 将所有属性变为必选

Partial 的反操作。将类型 T 的所有属性变为必选，确保对象包含所有必需字段。

原始类型
{
  a?: number
  b?: string
}
→ Required →
结果类型
{
  a: number
  b: string
}
示例代码 
interface Props {
  a?: number
  b?: string
}

// ✅ 正确：a 和 b 都是可选的
const obj: Props = { a: 5 }

// ❌ 错误：缺少必选属性 'b'
const obj2: Required<Props> = { a: 5 }
// 正确写法：{ a: 5, b: 'hello' }
Readonly<Type> 核心 只读类型 - 将所有属性变为只读

将类型 T 的所有属性变为 readonly，防止意外修改。常与 Object.freeze() 配合使用。

示例代码 
interface Config {
  host: string
  port: number
}

const config: Readonly<Config> = {
  host: 'localhost',
  port: 3000
}

config.host = 'example.com'  // ❌ 不能赋值给只读属性

// 配合 Object.freeze 使用
function freeze<T>(obj: T): Readonly<T> {
  return Object.freeze(obj)
}
Record<Keys, Type> 核心 记录类型 - 构造键值映射

构造一个对象类型，其属性键为 Keys，属性值类型为 Type。非常适合创建枚举映射或字典类型。

Record 类型转换流程

flowchart LR
    A["联合类型
'a' | 'b' | 'c'"] --> B[Record]
    C["值类型
number"] --> B
    B --> D["{
a: number
b: number
c: number
}"]
示例代码 
// 定义猫的名字和信息
type CatName = 'miffy' | 'boris' | 'mordred'

interface CatInfo {
  age: number
  breed: string
}

// 使用 Record 创建猫的映射
const cats: Record<CatName, CatInfo> = {
  miffy: { age: 10, breed: 'Persian' },
  boris: { age: 5, breed: 'Maine Coon' },
  mordred: { age: 16, breed: 'British Shorthair' }
}

// 等价于手动定义：
interface CatMap {
  miffy: CatInfo
  boris: CatInfo
  mordred: CatInfo
}
Pick<Type, Keys> 核心 选取类型 - 从类型中选取指定的键

从类型 T 中选取一组属性键 K 构造新类型。当你只需要对象的部分字段时使用。

原始类型 Todo
title: string
description: string
completed: boolean
→ Pick ['title','completed'] →
TodoPreview
title: string
completed: boolean
示例代码 
interface Todo {
  title: string
  description: string
  completed: boolean
}

// 只取 title 和 completed
type TodoPreview = Pick<Todo, 'title' | 'completed'>

const todo: TodoPreview = {
  title: '清洁房间',
  completed: false
}
// ✅ 不需要 description
Omit<Type, Keys> 核心 排除类型 - 从类型中排除指定的键

Pick 的反操作。从类型 T 中排除一组属性键 K，保留其余属性。

示例代码 
interface User {
  id: number
  name: string
  email: string
  password: string
}

// 排除敏感字段，创建安全的响应类型
type SafeUser = Omit<User, 'password'>
// { id: number; name: string; email: string }

// 原理：Omit = Pick + Exclude
type Omit<T, K extends keyof any> = Pick<T, Exclude<keyof T, K>>

联合类型操作

过滤和提取联合类型的工具集合

Exclude<Union, Excluded> 核心 排除类型 - 从联合类型中排除指定成员

从联合类型 U 中排除可赋值给 E 的类型成员。

示例代码 
// 基本用法
type T0 = Exclude<'a' | 'b' | 'c', 'a'>
// 结果: 'b' | 'c'

// 排除函数类型
type T1 = Exclude<string | number | (() => void), Function>
// 结果: string | number

// 实际应用：排除危险操作
type Operations = 'getUser' | 'createUser' | 'deleteUser'
type SafeOps = Exclude<Operations, 'deleteUser'>
// 'getUser' | 'createUser'
Extract<Type, Union> 核心 提取类型 - 从类型中提取可赋值的成员

Exclude 的反操作。从类型 T 中提取可赋值给 U 的类型成员。

示例代码 
// 基本用法
type T0 = Extract<'a' | 'b' | 'c', 'a' | 'f'>
// 结果: 'a'

// 提取函数类型
type T1 = Extract<string | number | (() => void), Function>
// 结果: () => void

// 实际应用：只保留读操作
type AllOps = 'getUser' | 'createUser' | 'deleteUser'
type ReadOps = Extract<AllOps, 'getUser'>
// 'getUser'
NonNullable<Type> 常用 非空类型 - 排除 null 和 undefined

从类型 T 中排除 null 和 undefined。在处理可空值时非常有用。

可空类型
string | null | undefined
→ NonNullable →
非空类型
string
示例代码 
// 基本用法
type T0 = NonNullable<string | number | undefined>
// 结果: string | number

// 实际应用：处理 API 响应
function processResult(
  result: string | null | undefined
): NonNullable<string | null | undefined> {
  return result ?? 'default'
}

// 确保返回值永远不为空
const value = processResult(null)  // 'default'
const value2 = processResult('hello')  // 'hello'

函数操作

提取和操作函数签名的工具集合

Parameters<Type> 核心 参数类型 - 提取函数参数类型的元组

提取函数类型 T 的参数类型，返回一个元组类型。

Parameters 类型提取

flowchart LR
    A["函数签名
function greet(
name: string,
age: number
): void"] --> B["Parameters<T>"]
            B --> C["元组类型
[name: string,
age: number]"]
示例代码 
declare function greet(name: string, age: number): void

// 提取参数类型
type Params = Parameters<typeof greet>
// 结果: [name: string, age: number]

// 实际应用：创建类型安全的包装函数
function callWithDefaults(
  fn: (...args: Parameters<typeof greet>) => void
) {
  fn('Alice', 30)  // ✅ 类型安全
}
ConstructorParameters<Type> 常用 构造函数参数类型 - 提取构造函数参数的元组

提取构造函数类型 T 的参数类型，返回一个元组类型。

示例代码 
class Article {
  constructor(
    public title: string,
    public content?: string
  ) {}
}

// 提取构造函数参数
type Params = ConstructorParameters<typeof Article>
// 结果: [title: string, content?: string]

// 实际应用：实例缓存工厂
class InstanceCache<T extends new (...args: any[]) => any> {
  private cache = new Map<string, InstanceType<T>>()

  getInstance(
    ...args: ConstructorParameters<T>
  ): InstanceType<T> {
    const key = JSON.stringify(args)
    if (!this.cache.has(key)) {
      this.cache.set(key, new (...args))
    }
    return this.cache.get(key)!
  }
}
ReturnType<Type> 核心 返回类型 - 提取函数的返回类型

提取函数类型 T 的返回类型。

示例代码 
function getUser() {
  return { id: 1, name: 'Alice', age: 30 }
}

// 提取返回类型
type User = ReturnType<typeof getUser>
// 结果: { id: number; name: string; age: number }

// 确保变量类型与函数返回值一致
const user: User = getUser()
InstanceType<Type> 常用 实例类型 - 提取构造函数创建的实例类型

提取构造函数类型 T 创建的实例类型。

示例代码 
class Cat {
  name: string
  constructor(name: string) {
    this.name = name
  }
}

// 提取实例类型
type CatInstance = InstanceType<typeof Cat>
// 结果: Cat

// 使用
function createCat(name: string): CatInstance {
  return new Cat(name)
}
NoInfer<Type> 进阶 禁止推断类型 - 阻止类型推断向指定类型传播

阻止 TypeScript 将某些参数推断到泛型参数中。确保默认值的类型必须来自其他参数。

示例代码 
// 定义红绿灯类型
function createStreetLight<C extends string>(
  colors: C[],
  defaultColor?: NoInfer<C>  // 禁止从这里推断 C
) {
  // ...
}

// ✅ 正确：'red' 在 colors 数组中
createStreetLight(['red', 'yellow', 'green'], 'red')

// ❌ 错误：'blue' 不在 colors 数组中
createStreetLight(['red', 'yellow', 'green'], 'blue')

字符串操作

编译时字符串转换工具

Uppercase / Lowercase / Capitalize / Uncapitalize 常用 字符串大小写转换

四个内置的字符串操作类型，在模板字面量类型中非常强大。

输入
'hello'
→ Uppercase → 'HELLO'
→ Capitalize → 'Hello'
→ Uncapitalize → 'hello'
→ Lowercase → 'hello'
示例代码 
// Uppercase: 字符串转大写
type T1 = Uppercase<'hello'>      // 'HELLO'
type T2 = Uppercase<'foo' | 'bar'> // 'FOO' | 'BAR'

// Lowercase: 字符串转小写
type T3 = Lowercase<'HELLO'>      // 'hello'

// Capitalize: 首字母大写
type T4 = Capitalize<'hello'>     // 'Hello'

// Uncapitalize: 首字母小写
type T5 = Uncapitalize<'Hello'>   // 'hello'

实际应用：事件系统命名 

// 配合模板字面量类型自动生成事件名
type EventName<T extends string> = `on${Capitalize<T>}`

type ClickEvent = EventName<'click'>     // 'onClick'
type FocusEvent = EventName<'focus'>     // 'onFocus'
type BlurEvent = EventName<'blur'>       // 'onBlur'

其他实用类型

异步处理和其他实用工具

Awaited<Type> 核心 解包类型 - 递归解包 Promise 类型

递归解包 Promise 类型，模拟 await 的行为。处理多层 Promise 嵌套时非常有用。

Awaited 解包流程

flowchart LR
    A["Promise<string>"] --> B[Awaited]
    B --> C["string"]
    
    D["Promise<Promise<number>>"] --> E[Awaited]
    E --> F["number"]
示例代码 
// 基本用法
type A = Awaited<Promise<string>>
// 结果: string

// 递归解包嵌套 Promise
type B = Awaited<Promise<Promise<number>>>
// 结果: number

// 实际应用：提取异步函数的最终返回类型
async function fetchUser(id: number) {
  const res = await fetch(`/api/users/${id}`)
  return res.json()
}

// 提取实际用户类型
type ActualUser = Awaited<ReturnType<typeof fetchUser>>

综合案例：API 类型系统

组合使用多个工具类型构建完整的类型系统

完整示例 
// ============================================
// 1. 定义基础类型
// ============================================
interface User {
  id: number
  name: string
  email: string
  password: string
  createdAt: Date
}

// ============================================
// 2. Record: 构造 API 端点映射
// ============================================
type ApiEndpoints = Record<
  'getUser' | 'updateUser' | 'deleteUser',
  string
>

const endpoints: ApiEndpoints = {
  getUser: '/api/users/:id',
  updateUser: '/api/users/:id',
  deleteUser: '/api/users/:id'
}

// ============================================
// 3. Pick + Omit: 创建安全的 DTO
// ============================================
type CreateUserDTO = Omit<User, 'id' | 'createdAt'>
type UserResponse = Omit<User, 'password'>

// ============================================
// 4. Partial: 支持部分更新
// ============================================
type UpdateUserDTO = Partial<Omit<User, 'id' | 'createdAt'>>

// ============================================
// 5. Parameters + ReturnType: 提取函数签名
// ============================================
async function fetchUser(id: number): Promise<UserResponse> {
  const res = await fetch(`/api/users/${id}`)
  return res.json()
}

type FetchUserParams = Parameters<typeof fetchUser>  // [id: number]
type FetchUserReturn = ReturnType<typeof fetchUser>  // Promise<UserResponse>

// ============================================
// 6. Awaited: 解包 Promise 获取最终类型
// ============================================
type ActualUser = Awaited<ReturnType<typeof fetchUser>>

// ============================================
// 7. Extract + Exclude: 过滤可选操作
// ============================================
type ReadOps = 'getUser' | 'listUsers' | 'searchUsers'
type WriteOps = 'createUser' | 'updateUser' | 'deleteUser'
type AllOps = ReadOps | WriteOps

type SafeOps = Exclude<AllOps, 'deleteUser'>
type ReadOnlyOps = Extract<AllOps, ReadOps>
