基本语法

遍历键创建新类型

[K in keyof T]: V 核心 映射类型 - 遍历对象的每个键

映射类型工作原理

flowchart LR
    A["原始类型
User { id, name }"] --> B["映射 [K in keyof T]"]
            B --> C["遍历每个键"]
            C --> D["新类型
ReadonlyUser"]
基本语法 
// 基本映射类型
type Readonly<T> = {
  readonly [K in keyof T]: T[K]
}

// 使用
interface User {
  id: number
  name: string
}

type ReadonlyUser = Readonly<User>
// { readonly id: number; readonly name: string }

键修饰符

添加或移除修饰符

修饰符操作 核心
语法 作用 示例
readonly [K in keyof T] 添加只读 Readonly<T>
[K in keyof T]? 添加可选 Partial<T>
-readonly [K in keyof T] 移除只读 Mutable<T>
[K in keyof T]-? 移除可选 Required<T>
示例 
// 移除只读
type Mutable<T> = {
  -readonly [K in keyof T]: T[K]
}

// 移除可选
type Required<T> = {
  [K in keyof T]-?: T[K]
}

键重映射（as）

TypeScript 4.1+ 新特性

[K in keyof T as NewKey] 进阶 键重映射 - 重命名或过滤键
添加前缀 
// 添加 get 前缀
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K]
}

interface User {
  name: string
  age: number
}

type UserGetters = Getters<User>
// {
//   getName: () => string
//   getAge: () => number
// }
过滤键 
// 只保留字符串类型的属性
type OnlyStrings<T> = {
  [K in keyof T as T[K] extends string ? K : never]: T[K]
}

interface Mixed {
  name: string
  age: number
  email: string
}

type StringProps = OnlyStrings<Mixed>
// { name: string; email: string }

内置映射类型

TypeScript 提供的工具

内置工具类型 核心
类型 实现 作用
Partial<T> { [K in keyof T]?: T[K] } 所有属性可选
Required<T> { [K in keyof T]-?: T[K] } 所有属性必选
Readonly<T> { readonly [K in keyof T]: T[K] } 所有属性只读
Pick<T,K> { [P in K]: T[P] } 选取指定键
Record<K,V> { [P in K]: V } 构造键值映射

高级模式

组合使用映射类型

映射类型 + 条件类型 进阶 
// 将函数包装为 Promise
type Promisify<T> = {
  [K in keyof T]: T[K] extends (...args: infer A) => infer R
    ? (...args: A) => Promise<R>
    : T[K]
}

interface Api {
  getUser(id: number): User
  getPost(id: number): Post
}

type AsyncApi = Promisify<Api>
// {
//   getUser(id: number): Promise<User>
//   getPost(id: number): Promise<Post>
// }

实战案例

真实场景中的应用

案例 1：表单状态管理 常用 
interface FormState {
  name: string
  email: string
  age: number
}

// 为每个字段创建状态对象
type FieldState<T> = {
  [K in keyof T]: {
    value: T[K]
    error: string | null
    touched: boolean
  }
}

type FormState = FieldState<FormState>
// {
//   name: { value: string; error: string | null; touched: boolean }
//   email: { value: string; error: string | null; touched: boolean }
//   age: { value: number; error: string | null; touched: boolean }
// }
案例 2：类型安全的配置验证 进阶 
interface Config {
  database: {
    host: string
    port: number
  }
  cache: { ttl: number }
  logging: boolean
}

// 为每个字段创建验证器
type Validators<T> = {
  [K in keyof T]: T[K] extends object
    ? Validators<T[K]>
    : (value: any) => boolean
}

const validators: Validators<Config> = {
  database: {
    host: (v) => typeof v === 'string',
    port: (v) => typeof v === 'number' && v > 0
  },
  cache: { ttl: (v) => typeof v === 'number' && v > 0 },
  logging: (v) => typeof v === 'boolean'
}
案例 3：API 方法异步化 常用 
// 将所有方法的返回值包装为 Promise
type PromisifyMethods<T> = {
  [K in keyof T]: T[K] extends (...args: infer A) => infer R
    ? (...args: A) => Promise<R>
    : T[K]
}

interface SyncApi {
  getUser(id: number): User
  getPost(id: number): Post
  name: string
}

type AsyncApi = PromisifyMethods<SyncApi>
// {
//   getUser(id: number): Promise<User>
//   getPost(id: number): Promise<Post>
//   name: string
// }
