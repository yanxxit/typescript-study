基础语法

定义和使用接口

interface 核心 接口 - 定义对象的结构契约

Interface 是对对象结构的契约定义，描述了一个对象"应该长什么样"，但不包含具体实现。

接口定义
User { id, name, email }
→ 约束 →
对象必须符合
{ id: 1, name: 'Alice', email: '...' }
示例代码 
// 定义接口
interface User {
  id: number
  name: string
  email: string
}

// 使用接口：对象必须符合这个结构
const user: User = {
  id: 1,
  name: 'Alice',
  email: 'alice@example.com'
}

// ❌ 缺少属性会报错
const user2: User = { id: 2, name: 'Bob' }
// 报错：缺少 email 属性
函数类型接口 常用 描述函数的签名
示例代码 
interface SearchFunc {
  (source: string, subString: string): boolean
}

// 使用
const mySearch: SearchFunc = function(src, sub) {
  let result = src.search(sub)
  return result > -1
}

属性修饰符

可选、只读等修饰符

可选属性 (?) 核心 属性可以不存在
示例代码 
interface User {
  id: number
  name: string
  email?: string    // 可选
  phone?: string    // 可选
}

// ✅ 正确
const user1: User = { id: 1, name: 'Alice' }

// ✅ 正确
const user2: User = {
  id: 2,
  name: 'Bob',
  email: 'bob@example.com'
}
只读属性 (readonly) 核心 属性不可修改
示例代码 
interface Config {
  readonly host: string
  readonly port: number
}

const config: Config = { host: 'localhost', port: 3000 }
config.host = 'example.com'  // ❌ 报错：只读属性不能修改
属性修饰符对比
修饰符 作用 示例
无 必选属性 name: string
? 可选属性 age?: number
readonly 只读属性 readonly id: number

接口继承

使用 extends 继承其他接口

单继承 核心

接口继承关系

flowchart TD
    A["Animal
name: string
age: number"] --> B["Dog
breed: string
bark(): void"]
示例代码 
interface Animal {
  name: string
  age: number
}

interface Dog extends Animal {
  breed: string
  bark(): void
}

// Dog 必须包含 Animal 的所有属性
const dog: Dog = {
  name: 'Rex',
  age: 3,
  breed: 'German Shepherd',
  bark() { console.log('Woof!') }
}
多继承 常用
示例代码 
interface Shape {
  color: string
}

interface PenStroke {
  penWidth: number
}

interface Square extends Shape, PenStroke {
  sideLength: number
}

// Square 包含 Shape、PenStroke 和自身的所有属性
const square: Square = {
  color: 'blue',
  penWidth: 5,
  sideLength: 10
}

接口实现（implements）

类实现接口

implements 核心 类必须实现接口的所有方法和属性

类实现接口

flowchart LR
    A["interface Printable
print(): void"] --> B["class Document
implements Printable"]
    B --> C["print() { ... }
必须实现"]
示例代码 
interface Printable {
  print(): void
}

interface Loggable {
  log(message: string): void
}

class Document implements Printable, Loggable {
  constructor(public title: string) {}

  print() {
    console.log(`打印: ${this.title}`)
  }

  log(message: string) {
    console.log(`[${this.title}] ${message}`)
  }
}

索引签名

处理动态属性名

[key: string]: Type 常用 索引签名 - 描述动态属性
示例代码 
interface StringArray {
  [index: string]: string
}

const colors: StringArray = {
  red: '#ff0000',
  green: '#00ff00',
  blue: '#0000ff'
}

// 数字索引签名
interface NumberMap {
  [index: number]: string
}

const arr: NumberMap = ['a', 'b', 'c']
console.log(arr[0])  // 'a'

索引签名的约束

索引签名的值类型必须兼容所有显式定义的属性类型：

interface Config {
  [key: string]: string  // 索引签名的值类型是 string
  name: string           // ✅ 兼容
  // age: number          // ❌ 报错：number 不兼容 string
}

声明合并

同名接口自动合并

Declaration Merging 进阶 Interface 独有的特性

声明合并流程

flowchart LR
    A["interface User
name: string"] --> C["合并后"]
    B["interface User
age: number"] --> C
    C --> D["interface User
name: string
age: number"]
示例代码 
interface User {
  name: string
}

interface User {
  age: number
}

// 合并后相当于：
// interface User {
//   name: string
//   age: number
// }

const user: User = { name: 'Alice', age: 30 }  // ✅

合并冲突

如果同名属性类型不同，会报错：

interface A { x: number }
interface A { x: string }  // ❌ 报错：x 的类型冲突

案例 2：Repository 模式 常用 
interface Repository<T> {
  findById(id: string): T | null
  findAll(): T[]
  save(entity: T): void
  delete(id: string): boolean
}

class UserRepository implements Repository<User> {
  private users: User[] = []

  findById(id: string): User | null {
    return this.users.find(u => u.id === id) || null
  }

  findAll(): User[] {
    return this.users
  }

  save(user: User): void {
    this.users.push(user)
  }

  delete(id: string): boolean {
    const index = this.users.findIndex(u => u.id === id)
    if (index !== -1) {
      this.users.splice(index, 1)
      return true
    }
    return false
  }
}
案例 3：事件系统 进阶 
interface EventMap {
  click: { x: number; y: number }
  keydown: { key: string; code: string }
  resize: { width: number; height: number }
}

class EventEmitter<T extends Record<string, any>> {
  private listeners: { [K in keyof T]?: Array<(data: T[K]) => void> } = {}

  on<K extends keyof T>(event: K, listener: (data: T[K]) => void) {
    if (!this.listeners[event]) {
      this.listeners[event] = []
    }
    this.listeners[event]!.push(listener)
  }

  emit<K extends keyof T>(event: K, data: T[K]) {
    this.listeners[event]?.forEach(fn => fn(data))
  }
}

const emitter = new EventEmitter<EventMap>()
emitter.on('click', (data) => {
  console.log(data.x, data.y)  // 类型安全
})
