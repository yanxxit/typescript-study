# modules

## type-fest
TypeScript 实用类型集合，涵盖对象、字符串、数字、函数等各类工具类型。
3.3 亿的周下载量，不是 type-fest 自己有多火，而它被当做依赖被上层工具安装，看看你的 node_modules 目录，也许就它的身影~

type-fest 对 TS 项目来说几乎是刚需，毕竟 TS 内置的工具类型管不到太多的应用场景。

详细文档：[type-fest 使用指南](../docs/modules/type-fest.md)

## TypeScript 内置工具类型

TypeScript 自带的全局工具类型，无需安装依赖。涵盖对象操作（Partial、Required、Readonly、Record、Pick、Omit）、联合类型操作（Exclude、Extract、NonNullable）、函数操作（Parameters、ReturnType、InstanceType）、字符串操作（Uppercase、Lowercase、Capitalize）等。

详细文档：[TypeScript 内置工具类型指南](../docs/modules/typescript-builtin-types.md)
